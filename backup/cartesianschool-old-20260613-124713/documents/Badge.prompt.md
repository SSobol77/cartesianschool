Small pill label — status chips, category tags, and the bold mono metric chips on portfolio cards.

```jsx
<Badge tone="indigo" dot>Websites for Local Businesses</Badge>
<Badge tone="before" metric>21.8 s load</Badge>
<Badge tone="pass">Audited</Badge>
```

Tones: `indigo` (default), `neutral`, `pass`, `before`, `fail`, `onDark`. Set `dot` for a pulsing status dot, `metric` for the mono before/after chips.
