Rounded surface container — the base for most boxed content. Set `interactive` for clickable cards (portfolio, steps).

```jsx
<Card interactive>…</Card>
<Card tone="space">…dark panel…</Card>
<Card tone="gradient">…pricing CTA…</Card>
```

Tones: `default` (white), `subtle` (slate-50), `space` (dark gradient), `gradient` (brand). Radius is 2xl; override `padding` as needed.
